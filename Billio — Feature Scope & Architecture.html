v1 Strategy

Free তে core flow perfect করো — শুধু invoice generate + attach + download। Pro তে template builder ও WhatsApp। WordPress.org এ submit করার আগে free version এ ৫ স্টার রেটিং দরকার — তাই free experience flawless হতে হবে।

DB Structure

Invoice meta কোথায় store হবে ▼

Custom table না — WooCommerce order meta তে store করব:

_billio_invoice_number → "INV-2026-0001" _billio_invoice_date → timestamp _billio_invoice_pdf_path → relative path (uploads/billio/...)
কেন custom table নয়? v1 এ scope ছোট রাখতে। Order meta সহজ, HPOS compatible। পরে query দরকার হলে custom table add করা যাবে।

Security Rules

প্রতিটি action এ enforce করতে হবে ▼
  • ✓ Admin download: current_user_can('manage_woocommerce') check
  • ✓ Customer download: order owner verify করতে হবে ($order->get_customer_id() === get_current_user_id())
  • ✓ AJAX: nonce verify (check_ajax_referer)
  • ✓ Settings save: sanitize_text_field() + wp_verify_nonce()
  • ✓ PDF file URL direct access block — uploads/billio/ তে .htaccess
  • ⚠ is_pro() check ছাড়া কোনো Pro class load করা যাবে না
🏗️

HPOS Compatibility

WooCommerce High-Performance Order Storage ▼

WooCommerce 7.1+ এ HPOS default। billio.php এ declare করতে হবে:

add_action( 'before_woocommerce_init', function() { if ( class_exists( \Automattic\WooCommerce\Utilities\FeaturesUtil::class ) ) { \Automattic\WooCommerce\Utilities\FeaturesUtil ::declare_compatibility( 'custom_order_tables', __FILE__, true ); } } );

সব order query অবশ্যই wc_get_order() API দিয়ে করতে হবে — direct $wpdb query নয়।
